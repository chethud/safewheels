# Safe Wheels Tours & Travels

Premium single-page website redesign for Safe Wheels Tours & Travels (Mysuru, est. 1999).

## Stack

- Next.js 16 (App Router)
- React 19
- Tailwind CSS 4
- Framer Motion
- TypeScript

## Develop

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Build

```bash
npm run build
npm start
```

## Notes

- Booking enquiries open WhatsApp with a pre-filled message (no live payment system).
- Fleet and client imagery is sourced from the existing Safe Wheels website where available.
- Brand logo is in `public/images/logo.webp`.
